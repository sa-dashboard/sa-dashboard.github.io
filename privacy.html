Privacy Policy

Last updated: 18 November 2026

Social Analytics (personal) ("the application") is a self-hosted tool used only by its owner, on the owner's own computer, with the owner's own social media accounts.

Data the application accesses

When the owner connects a YouTube channel, the application requests read-only access through Google OAuth with these scopes:

  • youtube.readonly: channel details and the list of published videos (titles, descriptions, thumbnails, durations, public statistics).
  • yt-analytics.readonly: YouTube Analytics reports (views, watch time, average view duration, shares, subscribers gained and lost).

How the data is used

The data is used only to display dashboards and trends to the owner. It is not used for advertising, it is not sold, and it is not shared with or transferred to any third party.

Storage and security

All data is stored in a database on the owner's own computer. OAuth access and refresh tokens are stored encrypted (AES-256-GCM). The application does not send YouTube data to any server operated by the application.

Retention and deletion

Data is kept until the owner disconnects the account in the application, which deletes the account and all of its stored data. Access can also be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact
